# Getting Started

## Installation

Add the NuGet package to your project:

```
dotnet add package FromModel
```

Or edit your `.csproj` directly:

```xml
<PackageReference Include="FromModel" Version="*" />
```

Because `FromModel` is a source generator, the package is automatically treated as a development dependency (`PrivateAssets="all"`). It adds no runtime assembly reference — consumers only see the generated source.

## Requirements

- .NET SDK 6.0 or later (the generator itself targets `netstandard2.0` for maximum compatibility)
- C# 9.0 or later in your consuming project (for `init`-only properties and `required` modifier support)

## Your first DTO

### 1. Define a model

```csharp
// Models/Product.cs
public class Product
{
    public required string Name { get; set; }
    public string Description { get; set; } = "";
    public decimal Price { get; set; }
    public bool InStock { get; set; }
}
```

### 2. Declare a partial DTO class

Create an empty `partial class` and apply `[FromModel]`:

```csharp
// DTOs/ProductDto.cs
using FromModel;

[FromModel(typeof(Product))]
internal partial class ProductDto { }
```

That is all the code you need to write. The generator does the rest at build time.

### 3. Build

```
dotnet build
```

The generator emits the following file into your project's intermediate output:

```csharp
// <auto-generated/>
#nullable enable

internal partial class ProductDto
{
    public required string Name { get; set; }
    public string Description { get; set; } = "";
    public decimal Price { get; set; }
    public bool InStock { get; set; }
}
```

### 4. Use the DTO

```csharp
var dto = new ProductDto
{
    Name        = "Widget",
    Description = "A very fine widget",
    Price       = 9.99m,
    InStock     = true,
};
```

## Viewing generated files

To persist generated files to disk (useful for debugging), add this to your `.csproj`:

```xml
<PropertyGroup>
  <EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>
</PropertyGroup>
```

Generated files appear under `obj/Debug/<tfm>/generated/FromModel/FromModel.FromModelGenerator/`.

## Namespaces

The generated `partial class` is placed in the same namespace as the partial declaration in your own file. If your DTO is in `MyApp.Dtos`, the generated file respects that:

```csharp
namespace MyApp.Dtos;

[FromModel(typeof(Product))]
internal partial class ProductDto { }
```
